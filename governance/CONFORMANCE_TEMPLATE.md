# CAES Conformance Statement Template

Implementations claiming CAES compliance MUST publish a complete Conformance Statement.

---

## Required Fields

### CAES Version
(e.g., v0.1.1)

### Claimed Compliance Level
Level 1 / Level 2 / Level 3

### Effect Boundary Categories Governed
(List categories 1–6 and classification: Hard / Soft)

### Receipt Verification Method
Describe cryptographic verification and trust root.

### PolicyHash Canonicalization Method
Specify canonical representation (e.g., JCS).

### Fail-Closed Enforcement Mechanism
Describe enforcement model.

### Spine Storage Model
Describe append-only guarantees and immutability controls.

---

## Optional

- Public evidence pack
- Independent audit
- Test harness results

---

Incomplete statements MUST NOT reference CAES compliance.
