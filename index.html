CAES

Constitutional AI Execution Standard, v0.2.0, with CPP v1.0.

A conformant system proves, before execution, that the action was authorized.

CAES defines how decisions must be enforced. CPP defines how decisions must be determined. CPP v1.0 is required for CAES Level 2 and Level 3.
